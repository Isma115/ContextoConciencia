# Ejemplo web para NexusData

`ejemplo-nexusdata` es una página web pequeña y completamente local para probar las funcionalidades de NexusData.

## Cómo probarla

1. Abre NexusData y carga la carpeta `ejemplo-nexusdata` como proyecto.
2. En **Buscar**, prueba términos como `offline`, `validación`, `sostenibilidad` o `diagrama`.
3. Abre `index.html` en el visor HTML para probar la página y sus interacciones.
4. En **Mapa de Código**, selecciona `index.html`, `app.js`, `styles.css` o la carpeta completa.
5. Importa `docs/flujo-exploracion.nxd` desde la vista de diagramas.

## Qué contiene

- `index.html`: página de ejemplo con navegación, tarjetas, filtro y modo claro.
- `styles.css`: estilos responsive sin dependencias externas.
- `app.js`: interacciones locales para el filtro, el tema y el recorrido.
- `data/recursos.json`: datos estructurados para probar la indexación JSON.
- `docs/notas-de-prueba.md`: contenido de búsqueda y contexto del proyecto.
- `docs/flujo-exploracion.nxd`: diagrama con nodos espaciados y varias direcciones de flecha.

No hace falta instalar nada ni tener conexión a internet.
