# Notas de prueba para NexusData

Este documento reúne palabras clave para comprobar el buscador y la lectura de documentos.

## Contexto

Atlas Local es una pequeña interfaz de ejemplo creada para trabajar con una carpeta **offline**. No utiliza API, login, CDN, fuentes remotas ni imágenes externas. El objetivo es que cada pieza pueda abrirse y entenderse desde el propio proyecto.

## Decisiones

- La validación de datos vive en `data/recursos.json`.
- La interacción del filtro y el cambio de tema vive en `app.js`.
- La estructura visual y el comportamiento responsive viven en `styles.css`.
- El flujo de selección, indexación y búsqueda está descrito en `docs/flujo-exploracion.nxd`.

## Palabras para buscar

Prueba con: **offline**, **validación**, **sostenibilidad**, **diagrama**, **recursos**, **tema claro**, **mapa de código** e **indexación**.
