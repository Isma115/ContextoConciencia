# Documento remoto de prueba

Este documento Markdown se sirve desde una fuente HTTP de prueba incluida en el proyecto **NexusData**.

## Objetivo

Comprobar que la aplicación puede:

- conectarse a un servidor mediante su dirección IP;
- obtener un documento remoto;
- guardar y buscar su contenido;
- volver a sincronizarlo después de un cambio.

## Datos de ejemplo

| Campo | Valor |
| --- | --- |
| Entorno | Pruebas |
| Formato | Markdown |
| Estado | Disponible |

> Si puedes leer este texto desde NexusData, la fuente remota funciona correctamente.
